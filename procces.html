Introduction

This portfolio was created to showcase my skills, projects, and personal approach to web development.
I aimed for a clean, minimalist design that reflects both functionality and aesthetic simplicity.

Planning & Design

Before writing any code, I started by planning the structure and layout of the website.

  • Minimalist style with a clean white background
  • Black text, and a bright accent color (#00bfff) to keep the interface modern and easy to read
  • I defined the main sections I wanted to include — such as About Me, Skills, Projects, and Contact — and sketched a simple layout to guide the development process.

Technologies Used

For building this portfolio, I utilized fundamental web technologies including HTML for structure, CSS for styling, and JavaScript for interactivity. This combination allowed me to create a responsive, clean, and dynamic user experience while keeping the code lightweight and maintainable.

Challenges & Solutions

During the development process, one of the main challenges I faced was implementing smooth animations that triggered on scroll. At first, the progress bars would animate only once or behave unexpectedly when scrolling back up. To solve this, I used the Intersection Observer API to detect when elements enter and leave the viewport, allowing the animation to reset and play every time they reappear.
Another challenge was ensuring that the layout remained clean and responsive across different screen sizes. I refined the CSS structure using flexbox and media queries to maintain a consistent look on both desktop and mobile devices.

Conclusion & Future Plans

Building this portfolio helped me strengthen my understanding of . It was a valuable hands-on experience where I combined both technical and visual aspects of web development.
In the future, I plan to expand the site by adding a dark mode, more interactive elements, and a blog section where I can share my learning journey, projects, and ideas.
